# Тренажер множення та ділення дробів

Інтерактивний веб-тренажер для учнів 5–6 класів.

## Що всередині
- **20 прикладів**: 10 достатнього + 10 високого рівня
- Множення та ділення звичайних дробів
- Онлайн-калькулятор з автоматичним перенесенням у поле відповіді
- Підказки, кнопка «Пропустити», перевірка відповідей
- Інтерфейс українською мовою
- Світлий сучасний дизайн

## Як користуватися
1. Відкрийте файл `index.html` у браузері  
   або увімкніть **GitHub Pages** (Settings → Pages → Source: Deploy from a branch → main / root)
2. Розв’язуйте приклади, використовуйте калькулятор і підказки

## Файли
- `index.html` — повністю робочий тренажер (HTML + CSS + JS)

Створено для зручного вивчення множення та ділення дробів.
